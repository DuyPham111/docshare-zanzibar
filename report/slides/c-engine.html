Engine chính là OpenFGA phiên bản 1.22.1, mã nguồn mở, dự án của CNCF, Okta FGA được xây trên nó. OpenFGA có đủ API bài cần, đặc biệt ListUsers và condition viết bằng CEL. DSL ngắn, và có thư viện JavaScript chính thức để parse DSL, nhờ vậy engine tự viết dùng chung file model. SpiceDB bám paper rất sát và về chức năng cũng làm được bài này; nhóm không chọn vì model OpenFGA có bộ chuyển DSL sang JSON chính thức cho JavaScript, nên engine tự viết đọc thẳng cùng file model, còn với schema Zed nhóm phải tự viết parser. Permify và Ory Keto có tập API hẹp hơn. OPA, Casbin, Cerbos là engine luật chứ không phải đồ thị quan hệ: kế thừa qua thư mục vẫn phải tự nạp dữ liệu.
