Trang demo là HTML và JavaScript thuần trên server riêng chỉ nghe localhost. Tính năng đắt giá nhất cho buổi trình bày là ma trận quyền của mọi user trên object đang chọn: bỏ chặn frank, gỡ bob khỏi nhóm hay chuyển thư mục, hàng nào đổi quyền thì viền vàng, thấy ngay một tuple ảnh hưởng tới ai. Endpoint cấp token dev không bao giờ nằm trong app chính, có test S1, và không có trong image Docker.
