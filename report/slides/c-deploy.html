Triển khai bằng Docker Compose. OpenFGA pin đúng phiên bản 1.22.1, có healthcheck; API chỉ khởi động khi OpenFGA healthy. Image API dùng node 22 alpine, chạy bằng user node, có healthcheck và dừng gọn. Có file override để OpenFGA lưu vào PostgreSQL 17, nhóm đã chạy thử và phát hiện mỗi lần API khởi động lại tạo thêm store, nên thêm bước dọn store cũ. Nhóm cũng gặp lỗi cú pháp JWT_SECRET bắt buộc của compose làm hỏng cả lệnh chỉ chạy OpenFGA, nên chuyển việc kiểm secret vào app.
